# MicTest.live

Free browser-based device tests — microphone, webcam, speakers, headphones, keyboard, mouse, click speed, double-click and dead pixels.

Everything runs locally in the browser using the Web Audio API, `getUserMedia` and `MediaRecorder`. No audio or video is uploaded.

Static site, no build step at deploy time. Pages are generated by the Python scripts in `build/` and committed as plain HTML.

## Deploy

Deployed on Vercel. `vercel.json` sets `cleanUrls`, security headers and a `Permissions-Policy` that allows microphone and camera on same-origin.
